# CodeAlpha URL Shortener

A URL shortening service built with Express.js and SQLite.

## Features
- Shorten long URLs into short codes
- Redirect from short code to original URL
- Simple REST API
- URL validation

## Tech Stack
Express.js | Node.js | SQLite | Nanoid

Server runs on `http://localhost:3000`
